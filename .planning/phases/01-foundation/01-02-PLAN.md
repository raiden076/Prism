**User queries:**
- `getUserById(db: D1Database, id: string): Promise<User | null>` — SELECT * FROM Users WHERE id = ?
- `getUserByPhone(db: D1Database, phoneNumber: string): Promise<User | null>` — SELECT * FROM Users WHERE phone_number = ?
- `getUserBySuperTokensId(db: D1Database, stUserId: string): Promise<User | null>` — SELECT * FROM Users WHERE supertokens_user_id = ?
- `createUser(db: D1Database, input: { role: UserRole; phoneNumber: string; regionScope?: string | null; supervisorId?: string | null; reporterId?: string | null }): Promise<User>` — INSERT with crypto.randomUUID(), return via getUserById
- `getUserDescendants(db: D1Database, userId: string): Promise<User[]>` — recursive CTE: WITH RECURSIVE subtree AS (SELECT id FROM Users WHERE id = ? UNION ALL SELECT u.id FROM Users u JOIN subtree s ON u.supervisor_id = s.id) SELECT * FROM Users WHERE id IN (SELECT id FROM subtree)

**Report queries:**
- `getReportById(db: D1Database, id: string): Promise<Report | null>`
- `getReportsByStatus(db: D1Database, status: ReportStatus, limit?: number): Promise<Report[]>` — ORDER BY created_at DESC, default limit 100
- `getReportsByReporter(db: D1Database, reporterId: string, limit?: number): Promise<Report[]>`
- `createReport(db: D1Database, input: { reporterId: string; latitude: number; longitude: number; r2ImageUrl: string; status?: ReportStatus }): Promise<Report>` — auto-generate digipin via latLngToDIGIPIN, INSERT, return
- `updateReportStatus(db: D1Database, reportId: string, newStatus: ReportStatus): Promise<Report | null>` — validate transition via isValidTransition, return null if invalid, UPDATE + return updated row
- `getNearbyReports(db: D1Database, latitude: number, longitude: number, radiusMeters: number, limit?: number): Promise<Array<Report & { distanceMeters: number }>>` — bounding box pre-filter then Haversine distance calculation in JS

**Intervention queries:**
- `getInterventionById(db: D1Database, id: string): Promise<Intervention | null>`
- `getInterventionsByReport(db: D1Database, reportId: string): Promise<Intervention[]>`
- `createIntervention(db: D1Database, input: { reportId: string; contractorId: string; repairTier: number; r2ProofImageUrl: string; fixLatitude: number; fixLongitude: number; spatialDriftCalc?: number }): Promise<Intervention>`

**Verification queries:**
- `getVerificationById(db: D1Database, id: string): Promise<Verification | null>`
- `getVerificationsByReport(db: D1Database, reportId: string): Promise<Verification[]>`
- `createVerification(db: D1Database, input: { reportId: string; verifierId: string; r2VerificationImageUrl: string; isResolved: boolean }): Promise<Verification>`

**Bounty queries:**
- `getBountyById(db: D1Database, id: string): Promise<VerificationBounty | null>`
- `getBountiesByStatus(db: D1Database, status: string, limit?: number): Promise<VerificationBounty[]>`
- `getBountiesNearby(db: D1Database, latitude: number, longitude: number, radiusMeters: number): Promise<Array<VerificationBounty & { distanceMeters: number }>>` — JOIN Reports for lat/lon, Haversine filter
- `createBounty(db: D1Database, input: { reportId: string; bountyAmount?: number; expiresAt: string }): Promise<VerificationBounty>`
- `claimBounty(db: D1Database, bountyId: string, userId: string): Promise<VerificationBounty | null>` — UPDATE bounty_status='claimed', claimed_by, claimed_at WHERE id=? AND bounty_status='available', return updated

**Whitelisted Source queries:**
- `getWhitelistedSourceById(db: D1Database, id: string): Promise<WhitelistedSource | null>`
- `getWhitelistedSourceByReference(db: D1Database, referenceId: string): Promise<WhitelistedSource | null>`
- `createWhitelistedSource(db: D1Database, input: { linkedUserId?: string; verifiedName: string; referenceId: string; approvalStatus?: string }): Promise<WhitelistedSource>`

**Hierarchy queries:**
